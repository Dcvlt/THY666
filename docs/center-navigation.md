# Center and arrow controls

| Control | On Play | In menus |
| --- | --- | --- |
| CENTER | Open Settings | Discard unfinished edit and return to the active workspace |
| RIGHT | Configured shortcut; Chords by default | Enter, edit, apply or run selected action |
| LEFT | Engines by default | Cancel draft or return one level |
| UP/DOWN | Views/Performance by default | Move selection or change draft |

Use RIGHT to apply before returning to the workspace. CENTER is never the confirmation
key. Numeric editors repeat while UP/DOWN is held and stop on release.

Settings → Controls configures each Play arrow or hides it. Hidden arrows have
no action/backlight. Lower musical controls keep their own lighting and do not
serve as menu navigation. Sequencer track settings return directly to their
editor with LEFT, preserving its selected step and playing surface.

The browser replica and device use these same C actions. Connected large pads
are inspection-only. See [Menus](menu-structure.md) and
[Center response](center-touch-response.md).

Every settings list ends in **Reset options** with a restore-arrow icon. RIGHT
opens a scoped confirmation with Cancel selected; UP/DOWN chooses Cancel or
Reset, and RIGHT executes that choice. LEFT cancels; CENTER cancels and returns
to the active workspace. Musical content and calibration are retained. See
[Reset options](reset-options.md) for each menu's scope.

In Harmony, LEFT opens its view picker, RIGHT opens Harmony settings and CENTER
opens global Settings. In Sequencer, CENTER opens global Settings from the
workspace and returns to the editor from track settings. The selected engine
and editor position are retained. Select another workspace in Engines.
