# Center and arrow controls

| Control | On Play | In menus |
| --- | --- | --- |
| CENTER | Open Settings | Discard unfinished edit and return to Play |
| RIGHT | Configured shortcut; Chords by default | Enter, edit, apply or run selected action |
| LEFT | Engines by default | Cancel draft or return one level |
| UP/DOWN | Views/Performance by default | Move selection or change draft |

Use RIGHT to apply before returning to Play. CENTER is never the confirmation
key. Numeric editors repeat while UP/DOWN is held and stop on release.

Settings → Controls configures each Play arrow or hides it. Hidden arrows have
no action/backlight. Lower musical controls keep their own lighting and do not
serve as menu navigation. Sequencer track settings return directly to their
editor with LEFT, preserving its selected step and playing surface.

The browser replica and device use these same C actions. Connected large pads
are inspection-only. See [Menus](menu-structure.md) and
[Center response](center-touch-response.md).
