# v0.2 board qualification checklist

The musical additions are implemented and locally tested. This checklist is for
the next physical session; it is not a record of passed hardware tests. No device
was connected or flashed during the local implementation work. Keep the earlier
known-good firmware/settings backup and current-song material separately.

## Controls and harmonic following

1. Connect the Client explicitly and identify the running build. Confirm normal
   pad attacks/releases on USB and DIN before enabling new policies.
2. In Chords, enable Live Update. Compare Keep key notes ON and OFF with C major
   then a different left chord. Only subsequent right-hand attacks should follow;
   held notes must retain their original pitch and release.
3. Enable Mute direct chord. Selecting harmony should silence only the ordinary
   direct left attack; Arp inputs and Pads-source recording still receive it.
4. Exercise key/scale shortcuts, custom scales and Cycle layout. Check that a
   held chord releases correctly after each change, including while strumming.

## Voicing

5. Compare Inversions and Drop voices first. I/II/III retain their established
   mutually exclusive inversion or independent drop behavior and LEDs.
6. Select Auto leading. Play C–E–G followed by F–A–C; listen for nearby octave
   movement. I/II/III and context inversion should do nothing in this mode.
   Changing key/scale, layout or mode and Panic should reset leading history.
7. Select Octave fold, then Guitar register. Check the resulting notes against
   the Client/OLED. These remain the same pitch classes in different registers;
   held notes do not change when switching modes. I/II/III stay inactive.
8. Repeat with Spread, bass octave, transpose, octave layers and one-shot strum.
   Those effects apply after voicing, so the final range can be wider. Check
   releases, sustain, overlap, Arp input and live-pad MPE without stuck notes.
9. Test a seven-distinct-pitch-class chord in Guitar register: it should retain
   the original voicing, with no omitted tone. Right-pad Guitar remains separate.

## Guidance

10. Open Chords → Harmony guidance. UP/DOWN browse, RIGHT opens/edits, LEFT
    returns, CENTER exits. The source key is a snapshot: reopen after changing it.
11. Add held notes, Use selected chord, and Clear captured notes. Check chord
    suggestions, scale discovery and modulation. There are 99 interval families;
    the 70 playable catalog families and original layouts retain their identities.
    Suggestions never audition notes or change settings. Pads remain playable.
12. Compare C major → G major: common C/D/E/G/A/B, added F-sharp, removed F, and
    a possible shared triad. Confirm destination edits do not alter the board key.
    Try dense input and empty input; there must be no inferred key from silence.

## Persistence, sequencing and stress

13. Save/reboot each new voicing selection. Current settings are v15 with the same
    payload size; imports from v1–v14 retain their old policy limits. Older firmware
    cannot import v15 exports. Guidance and leading history must reset on restore.
14. Exercise sequencer edit, record, undo/redo and song recall with nonempty
    material. Capacity remains 21 tracks, 512 live events, 256 take events and
    128 playback voices, plus the full 512-event undo arena now in SRAM.
15. Run both Arps and sequencer playback while changing views, playing/releasing
    overlapping chords and browsing guidance. Record any audible stalls, stuck
    notes or control delays. Stack high-water and worst-case foreground latency
    still need measurement on the board.

Record build, settings, route/channel, exact actions and observed result for each
failure. Updater interrupted-recovery, automatic rollback and cross-platform USB
qualification remain separate release milestones; this checklist does not imply
they are complete.
