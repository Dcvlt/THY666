The instrument, connected

A client.
In browser or Desktop

One Client, available in your browser and as a desktop app. Both bring together firmware updates, the live board display, settings, diagnostics and backups. Use desktop Chrome or Edge for the browser version, or the desktop app for native USB access. Choose Connect board when you’re ready.

Connected pads are for inspection; playing stays on the physical board. The screen and controls follow the instrument.

The firmware is optimized for the board’s fixed resources. Resource gauges and timed performance captures help the community investigate problems and compare improvements. Explore Client tools →

The road ahead.

v0.3.1 is the current accepted version. Next comes sequencer expansion in v0.4. Later milestones describe our direction, without promised release dates.

  1. v0.1 Initial release · hardware alpha

    Foundation.

    Chords, scales, MIDI, Arps, sequencing, views and expanded settings. Initial Windows desktop updater.

    Initial MVP
  2. v0.3.1 Current version

    Musical Expansion

    Browser and desktop Client, shared firmware updater, scoped expression settings and live-pad MPE. Harmony adds contextual chord suggestions and key exploration, alongside automatic voice leading, octave fold and guitar-register voicings.

    Focused board checks cover the musical additions, diagnostics and faster rendering. Broader restore coverage and macOS/Linux hardware qualification remain in progress.

    Available · hardware alpha
  3. v0.4 Next · sequencer expansion

    Pattern Evolution

    Chord-aware tracks and progression entry, with explicit root/scale following alongside existing absolute-note recordings. Integrate chords, voicings and Arps into the sequencing workflow.

    A fuller step-effects toolkit: gate and ties, probability, ratchets, loop conditions, playback directions, Euclidean fills and rotation. Expand pattern and song organization within the instrument’s timing and memory budgets.

    Planned
  4. Beyond Experimental features & MIDI

    New ways to play and connect.

    Explore drum mode, new engines and live musical processors, including repeating strum, note repeat, harmony and echo. Extend MIDI with clock/transport output, assignable CC and Program Change, and pedal integration.

    Exploration · scope to be defined

Updates can reset settings. Configuration backups are not raw flash images. Automatic rollback and interrupted-update recovery remain unverified. MPE currently serves live pads only.
