Know the current limits

An honest alpha.

Playing, menus, MIDI, Arps, sequencing, persistence and live Companion synchronization have been exercised on hardware. MPE currently serves live pads and cannot be combined with Arps or the sequencer. Some planned engines and advanced features remain unfinished.

The Windows native updater has passed a same-build installation. It reset settings during that test; explicit backup restoration recovered the tested configuration and survived a cold boot. Configuration backups are not raw flash images. Automatic rollback and interrupted-update recovery are not verified.
