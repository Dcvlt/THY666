The road ahead.

Hardware alpha today. Each milestone earns its place through testing on the instrument. Future version numbers below are proposed targets, not released builds or delivery dates.

  1. v0.1.0 Initial Release · hardware alpha

    Foundation.

    Chords, scales, MIDI, Arps, sequencing, views and expanded settings. Barebones updater on desktop (Windows)

    Available for testing
  2. v0.2 First Improvement · software alpha

    Integration.

    MacOS / Windows / Web client and updater. Original firmware through the Rust updater, and restoration checks with nonempty songs, libraries and calibrated profiles.

    Not yet qualified
  3. v0.3 Proposed · recovery milestone

    Confidence through interruption.

    Investigate interrupted-update recovery and configuration preservation. Prove failure handling before promising rollback.

    Planned research & validation
  4. Beyond Unversioned exploration

    More ways to compose.

    Named song and profile collections, advanced sequencing and additional engines. Scope follows musical testing and the instrument’s memory and timing budgets.

    Exploration

Updates can reset settings. Configuration backups are not raw flash images. Automatic rollback and interrupted-update recovery remain unverified. MPE currently serves live pads only.
